### Destin Jones — I build open-data instruments in public.

I take public data nobody has joined up and make it legible, fast, and
sourced to the record. Built in public, with Claude as the building partner.

**Open Overwatch** — everything that moves, where it really is: aircraft,
18,000 satellites, storms, quakes, and one continuous zoom from a street to
the cosmic web. Positions checked against NASA JPL.
→ [Live](https://destinjones.github.io/open-overwatch/) ·
  [Code](https://github.com/destinjones/open-overwatch)

**The Trigger** — open-source AI dividend readiness tracker. Git is the
database; every number links to its source.
→ [Live](https://destinjones.github.io/the-trigger) ·
  [Code](https://github.com/destinjones/the-trigger)

**CarFinder** — every new car, boat and aircraft on sale in 11 countries,
with the real on-road price for your state and every tax rule cited.
→ [Live](https://destinjones.github.io/carfinder/)

**The Money Files** — interactive, fully sourced ownership maps.

- Stack: vanilla JS / ES modules, TypeScript, Astro, Python, Leaflet, Cesium, three.js
- Method: no build step where I can avoid it, DOM-free tested cores, no number without a source link
- Reach me: [open an issue](https://github.com/destinjones/open-overwatch/issues) — hand-off offers welcome
